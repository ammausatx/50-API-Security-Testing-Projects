# 50 API Security Testing Projects

A structured, hands-on learning collection covering API reconnaissance, REST, authentication, authorization, GraphQL, OAuth, microservices, and advanced API security assessment.

> **Safety:** Perform testing only against intentionally vulnerable local labs or systems for which you have explicit authorization. Examples use synthetic data. Screenshots are simulated fictional training visuals, not genuine tool captures or scan evidence.

### Intermediate — Projects 16–35
BOLA, BFLA, object-property authorization, IDOR, mass assignment, SQL injection, NoSQL injection, command injection, SSRF, XSS through APIs, CORS, OAuth 2.0, OpenID Connect, session management, GraphQL, GraphQL authorization, file uploads, business logic, pagination/filtering, and API versioning.

### Advanced — Projects 36–50
Advanced JWT, OAuth token and scope abuse, advanced GraphQL, API gateway security, microservices, API-to-database trust boundaries, resource exhaustion, WebSocket, gRPC, secrets exposure, fuzzing, SAST and dependency assessment, CI/CD, OWASP API Top 10 full assessment, and enterprise API penetration testing.

## Standard project deliverables
Each project is intended to include:
- Objective, scope, prerequisites, and isolated lab setup
- Step-by-step testing workflow and tool commands
- Simulated editor, tool, and findings screenshots
- Findings, risk analysis, remediation, and validation
- Evidence and reporting guidance
- Completion checklist

## Screenshot disclaimer
All repository screenshots are purpose-built mockups containing fictional training data. They are illustrative walkthrough visuals, not screenshots of actual tool execution or real assessment evidence.
