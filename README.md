## Project deliverables
Each project includes objective, authorized scope, prerequisites, lab workflow, example requests/tool guidance, expected results, risk analysis, remediation, retesting, evidence/reporting guidance, references, and three simulated training illustrations.

## Screenshot disclaimer
All screenshots are fictional mockups, not actual tool execution, real API traffic, or assessment evidence.

## Safety and evidence
Use an isolated lab, synthetic identities, and low-volume requests. Define endpoints, methods, time windows, exclusions, and stop conditions. Never test third-party services without permission. Keep secrets out of source control and sanitize evidence.
